# BBBP 0.23 gap 单因素归因（2026-11-26，mol-gap）

> 起因：我们 BBBP scaffold RF 融合 AUC=0.9413，MoleculeNet Table 6 BBBP scaffold RF=0.714。
> 目标不是追平，而是把 gap 拆到可解释因素。先做 train-only 修复（`2026-11-26-mol-trainonly.md`），
> 确认 leakage 只值 ≤0.001，再做逐项切换。

## 摘要

**根因是 split 口径。** 只把「等大 scaffold 组洗牌」换成当前 DeepChem `ScaffoldSplitter` 的确定性排序
（组大小、首现索引降序，80/10/10），其他全部不动，5-seed mean AUC 从 0.9384096024006002 → 0.7196，
单项下降 0.21879154684504465，占 ours−official gap（0.22440960240060026）的
0.9749651730787943。ECFP bit、树数、去重、特征组合每项只值 ≤0.031。

## 装置与判据

- 脚本：`bench_mol_gap.py`；产物：`data/gap_metrics.json`；自检 `--selftest` 通过。
- 每个非 cumulative 变体**只改一个字段**，并在所有配置里使用严格 train-only scaler。
- 5 个 RF seed：42/0/7/2024/123；报告 mean、sample std、seed42 的 2000 次分层 bootstrap CI；
  测试集相同才给 paired delta CI，不同测试集标 `paired_delta_ci95_over_5_seeds: null`。
- 来源：论文正文 `https://arxiv.org/html/1703.00564v3#S6.T6`（80/10/10；非图模型默认 RDKit ECFP4；
  Table 6 BBBP scaffold RF 0.714；正文未写 bit 数）；DeepChem splitter
  `https://raw.githubusercontent.com/deepchem/deepchem/master/deepchem/splits/splitters.py`
  （`generate_scaffolds` 按 `(len(set), first_index)` 降序，`split()` 按该顺序填 80/10/10）。

## 机制核对

- 两种 split 的 test 交集只有 50/198，Jaccard=0.14450867052023122，确实是不同的 held-out 分子集。
- ours test：n=198 pos=155 neg=43（pos rate 0.7828282828282829）；
  DeepChem exact test：n=198 pos=102 neg=96（pos rate 0.5151515151515151）。
  train 也反向移动：ours pos rate 0.7645569620253164 → exact 0.8234177215189873。
  这既改了 scaffold 难度分布也改了标签构成，是 AUC 大幅回落的直接来源。
- cumulative 离官方只差 0.012227189517294401（ours 侧仍略高），说明把口径要素全部对齐后，
  0.23 基本消失；单因素 Δ 不可相加，因为 split 与特征/类别比例有交互。

## 逐条判断

1. bit 数、树数、去重都不是主因：|Δ|≤0.0039，CI 跨 0（去重 test 不同，但方向为 +0.0038）。
2. 特征里 MACCS 与 desc 合计值约 0.031，其中 MACCS 单独去掉掉 0.0188（CI 不跨 0）。
3. **split 一项解释 97.5% gap**；0.9413 不是"模型魔法"，是我们与 MoleculeNet 用了不同 scaffold 划分。

证据等级：A（单变量切换、DeepChem 源码移植、5 seed、配对 bootstrap、来源逐字落 JSON）。复算：
`python3 -u bench_mol_gap.py --selftest && python3 -u bench_mol_gap.py`。
